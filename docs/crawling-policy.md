# 크롤링 정책 및 운영 원칙

이 저장소는 웹 크롤링 구조와 안정적인 데이터 수집 파이프라인을 학습하기 위한 개인 프로젝트입니다. 특정 사이트의 데이터를 재배포하거나 상업적으로 이용하기 위한 목적이 아닙니다.

이 문서는 프로젝트의 운영 원칙을 설명하며, 특정 웹사이트에 대한 크롤링 허가나 법률 자문을 의미하지 않습니다. 크롤러를 실행하는 사용자는 실행 시점의 `robots.txt`, 이용약관, API 및 접근 정책, 관련 법령을 직접 확인해야 합니다. `robots.txt` 자체를 법적 허가로 간주하지 않습니다.

## 수집 범위와 사전 확인

- 실행 전에 대상 사이트의 `robots.txt`와 이용 정책을 확인합니다.
- 수집이 허용된 것으로 확인된 공개 페이지에 한해 요청합니다.
- `robots.txt`에서 `Disallow`로 지정된 경로에는 접근하지 않습니다.
- 로그인, 계정, 주문 등 제한된 영역은 수집 대상에서 제외합니다.
- 인증 우회, CAPTCHA 우회, 프록시 회전 등 접근 제한을 회피하는 기능을 사용하지 않습니다.
- 수집 데이터는 제목, 저자, 출판사, 출간일, 가격, 공개 URL 등 최소한의 상품·서지 메타데이터로 제한합니다.
- 본문, 리뷰, 목차 등 저작권 보호 콘텐츠의 대량 수집을 목적으로 하지 않습니다.

현재 코드에는 `robots.txt`를 자동으로 확인하거나 제한 영역을 자동 차단하는 기능이 포함되어 있지 않습니다. 따라서 실제 실행 전 대상 사이트의 정책과 환경 설정을 사용자가 직접 확인해야 합니다.

## 요청 부하 관리

현재 구현은 대상 서버에 불필요한 부하를 주지 않도록 다음 정책을 적용합니다.

- 단일 프로세스에서 순차적으로 요청합니다.
- 페이지 처리 사이에 설정된 범위의 임의 대기 시간을 적용합니다.
- HTTP `429 Too Many Requests` 응답이 발생하면 동일한 페이지를 다시 요청합니다.
- 현재 구현에서는 `429` 발생 후 60초 대기하며, 연속 3회 발생하면 작업을 종료합니다.
- 정상 응답을 받으면 연속 `429` 카운터를 초기화합니다.
- 동시 요청이나 병렬 크롤링을 수행하지 않습니다.

## 중단 후 재개와 중복 처리

- CSV 저장이 완료된 페이지를 체크포인트에 기록합니다.
- 중단 후 재실행하면 마지막으로 저장된 페이지 다음부터 수집을 재개합니다.
- 기존 CSV와 현재 페이지의 중복 데이터를 확인한 뒤 저장합니다.
- 중복 판단 기준은 다음 필드의 조합입니다.

```text
(title, primary_author, publisher, published_date)
```

- 페이지 처리 결과와 오류는 로컬 로그에 기록합니다.
- 현재 중복 기준은 상품 또는 에디션의 엄밀한 식별자를 대체하지 않습니다.

## 데이터 및 설정 관리

- 실제 수집 데이터와 실행 로그는 개인 학습 목적으로만 사용합니다.
- 실제 수집 데이터, 체크포인트, 로그, 환경별 설정값은 공개 저장소에 커밋하지 않습니다.
- 대상 URL, 카테고리 ID 등 환경별 설정은 `.env`로 분리하고, 실제 `.env` 파일은 버전 관리 대상에서 제외합니다.
- 공개되는 `.env.example`에는 실제 대상 사이트를 특정할 수 없는 일반화된 예시 값만 사용합니다.
- README, 테스트 코드, fixture, 노트북, 로그 예제 등에도 실제 대상 사이트나 수집 데이터를 식별할 수 있는 정보가 포함되지 않도록 커밋 전에 확인합니다.

## Disclaimer

사용자는 크롤러를 다른 사이트에 적용하기 전에 해당 사이트의 최신 `robots.txt`, 이용약관, API 정책 및 관련 법령을 직접 확인해야 합니다.

이 프로젝트의 구현이나 문서는 특정 웹사이트에 대한 크롤링 허가를 의미하지 않습니다. 정책이 불명확하거나 수집 제한이 확인되는 경우에는 수집을 진행하지 않습니다.
